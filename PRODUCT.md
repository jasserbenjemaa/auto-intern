# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Students, final-year engineering/university students, and recent graduates actively applying for internships (notably PFE / end-of-studies graduation internships) who need to streamline high-volume, customized job applications without sacrificing quality.

## Product Purpose
Auto-intern eliminates the tedious, repetitive overhead of internship searches and repetitive applications. It empowers candidates to discover opportunities, tailor resumes and cover letters for each specific role, and automate the application and dispatch process while keeping full visibility and control over application status.

## Positioning
Unlike generic job boards or blunt auto-click apply bots that send generic resumes, Auto-intern combines intelligent offer parsing, role-aligned CV tailoring, and managed application dispatch specifically calibrated for students securing high-stakes graduation internships.

## Operating Context
- Students preparing their end-of-studies (PFE) application campaigns under tight academic deadlines.
- Managing multiple application channels (direct company portals, recruiter emails, job boards).
- Desktop web environment where students manage enterprises, review extracted offers, preview generated application packets, monitor delivery statuses, and handle interview follow-ups.

## Capabilities and Constraints
- **Enterprise & Directory Management**: Full enterprise registry with date-stamped listings, workplace models (Remote, Hybrid, Onsite), branding colors/initials, and company profile editing/deletion.
- **Internship Offer Authoring**: Per-company internship listings with creation and editing flows for titles, descriptions, compensation, and full-time conversion opportunities.
- **Application Dossier Assembly**: Multi-offer selection bar, drawer preview, and queued batch application workflow with undo capability.
- **Centralized Workflows (Top Navigation)**:
  - *Companies* (`/dashboard`): Browse enterprises, manage listings, curate offers.
  - *Applications* (`/dashboard/emails`): Application dispatch log and status pipeline (applied, delivered, opened, invited, rejected).
  - *Scraper* (`/dashboard/scraper`): Automated scraping and ingestion of new internship listings.
  - *Profile* (`/dashboard/profile`): Student CV, education, skills, and base application materials.
- **Tech Stack**: Full-stack web application built on Next.js 16 (Turbopack, React 19, Tailwind CSS v4) with ShipCat neobrutalist styling.

## Product Principles
1. **High Quality over Blind Volume**: Tailored, contextually relevant applications beat spammy mass-submissions.
2. **Transparency and User Agency**: Never send an application or email without clear user visibility, history, and configurable review gates.
3. **Frictionless Workflow**: Minimize manual repetitive copy-pasting, letting the candidate focus on interview preparation.
4. **Reliability in Communication**: Accurate tracking of dispatched emails, contacts, and response timelines.
